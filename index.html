Chưa có playlist. Hãy thêm nguồn để bắt đầu.
Hỗ trợ phát HLS (.m3u8), MP4 / WebM, một số dạng luồng được trình duyệt hỗ trợ và ảnh camera. Nguồn HTTP, CORS, DRM hoặc yêu cầu header đặc biệt có thể không phát được trên GitHub Pages.

Thêm nguồn phát

Nhập URL playlist, stream đơn lẻ, dán nội dung hoặc tải tệp. Không cần cài đặt máy chủ.

Với URL playlist, máy chủ cần bật CORS cho trình duyệt. URL .m3u8 thường là stream HLS. Khi link không có đuôi rõ ràng, hãy chọn kiểu nguồn thủ công.

Có thể dùng JSON với các trường: name/title, url/stream/hls/m3u8, group/category, logo.
